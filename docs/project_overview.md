# Project Overview

**Secure Pay Vision** investigates machine-learning approaches to credit card fraud detection on the public Kaggle ULB dataset.

## Problem
Fraudulent transactions are extremely rare (about 0.17%), so models must be judged on how many frauds they catch (recall) and how many false alarms they raise (precision), not on accuracy.

## Approach
1. Load the dataset and stratify-split it into training and test sets, keeping the test set imbalanced.
2. Handle imbalance on the training data only: no handling, class weights, random undersampling, SMOTE.
3. Train Logistic Regression (standardised features) as an interpretable baseline and Random Forest as a non-linear model.
4. Evaluate on the untouched test set with precision, recall, F1, PR-AUC, ROC-AUC and confusion matrices.

## Scope and honesty notes
- The system scores transactions in batch. It has not been built or tested as a real-time service.
- Conclusions depend on one split and one threshold; see the README's limitations.
- See the README for the final results table and plots generated by `python -m src.train`.

## Future work
Cross-validation, threshold selection by cost, gradient-boosted models, probability calibration, drift monitoring and a streaming/API prototype.
